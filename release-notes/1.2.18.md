# Family Bridge 1.2.18

- Проверка пары дожидается восстановления сохранённой сессии. При отказе доступа приложение автоматически пробует обновить прежнюю авторизацию; одновременные проверки не запускают несколько обновлений токена.
- Сбой сети или отсутствие авторизации у уже подключённого приложения больше не создают новую анонимную учётную запись, которая не имеет доступа к прежней паре.
- Авторизация сохраняется заменой файла, с локальной восстановительной копией. Повреждённый файл не трактуется как первая установка. Старый сетевой клиент останавливает обновление токенов при замене.
- Потеря доступа к ранее работавшей паре больше не показывает приглашение создать её заново. Приложение сообщает, что подключение сохранено и проверка повторяется.
- Включены подготовленные изменения 1.2.17: более естественная манера речи без усиления слов-паразитов, сбалансированные примеры из исходного чата, явный Medium для всех запусков модели. Astra выбирается при наличии на клиенте.
- Путь профиля на Mac и Windows не меняется. Темы, история, текущие обсуждения и исходный чат не сбрасываются. Миграция хранения разговоров в этот срочный выпуск не включена.

Автоматическое восстановление требует ещё действующей прежней сессии. Этот выпуск не подменяет участника пары и не обещает восстановить уже утраченные серверные полномочия без подходящих сохранённых данных.
