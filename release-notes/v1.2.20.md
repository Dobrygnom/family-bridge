# Family Bridge 1.2.20

- Added remote technical reports and a request to run the official automatic updater.
- Automatically provision a separate encrypted support connection, with its own session, so a conversation authorization failure can be diagnosed remotely.
- Keep support polling independent of dialogue generation. Report captured time and mark stale state explicitly.
- Add a local authenticated operator interface that does not attach Electron Inspector.
- Restrict reports to technical metadata; exclude private text, credentials, paths and crash dumps. Ignore expired/replayed commands and preserve update safety gates.

Full support requires both applications to receive this release and connect once.
Command acceptance does not itself confirm a completed update; confirm the peer's
new version and boot ID in a subsequent report.
