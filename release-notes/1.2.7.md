# Family Bridge 1.2.7

- Подбор тем разделён на два этапа: содержательные вопросы из всего чата, затем объединение близких вопросов в полноценные разговоры. Без заданного числа тем и без отдельного пункта на каждый эпизод.
- Давность упоминания больше не считается решением вопроса. Для неопределённой актуальности добавлена отдельная пометка; такие темы можно проверить перед разрешением обсуждения.
- У каждого кандидата сохраняется внутреннее решение об отборе, объединении, переносе или исключении. Проверяются полнота ссылок и разделение адресатов.
- Список сохраняет порядок важности, а не пересортировывается по алфавиту. В раскрытой теме доступен контекст до 800 символов без прежней обрезки на 500.
- Массовое разрешение безопасных тем не включает темы, актуальность которых нужно проверить. Индивидуальный выбор остаётся доступен.
- Обновление сохраняет выбранный чат, темы, соединение и результаты. Повторный анализ при неизменном источнике не запускается только из-за новой версии приложения.

Генерация и сохранение предложений не дают разрешения отправлять их собеседнику.
