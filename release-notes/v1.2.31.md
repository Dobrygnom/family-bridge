# Family Bridge 1.2.31

- Remote diagnostics now include observed sleep, resume, screen lock and power-source events, plus long gaps in application execution. A gap alone is not labelled as sleep.
- Every diagnostic heartbeat includes the current stage and duration of dialogue and support polling, with the last failure stage and a safe error code retained after a retry. Network timeouts and cancelled requests are distinguished.
- Diagnostic metadata is bounded and excludes conversation text, file paths and credentials. Existing topics and conversations are preserved.
