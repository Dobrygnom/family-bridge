The bottom-left update control is hidden when no update is available, including during routine background checks. Installation and download controls appear only for an available update. The settings panel no longer offers a manual check button when there is nothing to install.

The source-chat page now scrolls as one page. Topic rows retain their natural height instead of being squeezed into the space left below the source card; the topic list no longer has a separate constrained scrollbar.

Validation: four focused update-state tests and desktop build. A short offline Electron layout regression reproduced a 1px topic list with the old CSS, then verified 68px rows and working page scroll at 1166x773, 1280x720 and 1920x1080 with the fix.
