# Family Bridge 2.0.0

- Adds an optional encrypted computer-helper channel that uses the helper's existing ChatGPT/Codex login. No paid API key and no credential sharing are required.
- Adds explicit off, host, client, and per-client revoke controls in Settings.
- Persists client jobs before sending and helper results before acknowledgement. Offline computers and temporary Codex usage limits no longer discard work.
- Routes dialogue generation, new-topic drafts, topic refinement, and portrait updates through the helper when client mode is enabled.
- Adds manual onboarding for people who do not yet have a psychologist chat.
- Makes the local model default account-aware. The helper always uses GPT-5.6 Luna with medium reasoning.
- Uses Realtime for normal compute delivery with a one-minute metadata-only fallback instead of high-frequency polling.
- Keeps the public build free of service-role credentials, master keys, or a universal diagnostic/compute capability.
