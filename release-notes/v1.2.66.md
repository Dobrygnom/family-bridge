# Family Bridge 1.2.66

- Every connected pair now provisions its own independent recovery capsule. If the dialogue authorization is lost, the existing logical pair, conversations, drafts and local history continue over a replacement transport instead of becoming a new chat.
- Realtime notifications replace high-frequency idle polling. Dialogue fallback runs every five minutes; support fallback and a compact metadata-only heartbeat run once per minute.
- Periodic support traffic no longer includes histories, operation timelines or application diagnostics. Detailed state is returned only to an explicit authenticated request from the connected peer.
- Removed the release-embedded pair-specific recovery capsule and all remaining couple-specific names from production prompts and controls. Participant names come from application settings and paired metadata.
- Updated Electron to 44.4.2.
- Added public-distribution security checks for privileged keys, private pair data, pair-member RLS and invitation binding.
