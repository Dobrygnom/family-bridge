# Family Bridge 1.2.24

- Проверка новых сообщений читает уже выбранный чат напрямую, без предварительной загрузки всего списка задач.
- При временной перегрузке Codex чтение автоматически повторяется с паузами и продолжает текущую страницу истории.
- Ошибка чтения больше не заменяется сообщением чужого браузерного канала `No handler registered for method: tools/list`.
- Запросы имеют уникальные идентификаторы; запрос, превысивший время ожидания, отменяется. Неполный или некорректный ответ не перезаписывает сохранённый контекст.
- Добавлены технические события прогресса чтения и локальная команда обновления выбранного исходного чата для диагностики без действий владельца.
