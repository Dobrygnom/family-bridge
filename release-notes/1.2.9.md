# Family Bridge 1.2.9

- Выбранные темы, пропущенные очередью, восстанавливаются автоматически. Свои разрешённые темы запускаются без повторных галочек; полученные от партнёра темы не запускаются второй раз на другом компьютере.
- Исходный разговор и продолжения показаны одной раскрываемой беседой. Одно поле внизу продолжает последнюю часть с учётом истории. Старые черновики сохраняются.
- Служебные проверки версии больше не передаются агентам как темы; ранее созданные служебные результаты скрыты, их файлы не удалены.
- Подготовленные первые реплики и ID запусков сохраняются до отправки: после сбоя используется тот же запрос, а не новый разговор. Незавершённые поручения восстанавливаются автоматически; временные ошибки повторяются с ограничением попыток.
- Обновления Windows и macOS устанавливаются без подтверждения после завершения текущих операций и диктовки. Приложение перезапускается с сохранёнными разговорами, очередью и черновиками. Уже установленная старая версия может один раз показать прежний запрос подтверждения при переходе на 1.2.9.
- Увеличено время повторных попыток атомарного сохранения при временной блокировке файла Windows.

Версия не сбрасывает контекст, выбранные темы, подключения или историю и не требует повторного анализа исходного чата.
# Спокойный список разговоров

Новые сообщения больше не раскрывают темы и форму продолжения автоматически. Ваш выбор раскрытых тем сохраняется; обновления не переставляют разговоры во время чтения.
