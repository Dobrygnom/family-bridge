# Family Bridge 1.0.0

## Что изменилось

- Новые реплики появляются прямо в открытом продолжении разговора — без обновления окна и переключения вкладок. После завершения переписка остаётся там же. Повторные события не дублируют сообщения, а запоздалое обновление состояния не затирает новые ответы.
- Рядом с собеседником и в заблокированном продолжении есть отдельная кнопка **«Проверить версию собеседника»**. Показаны ожидание, отсутствие ответа, ошибка и полученная версия. Запрос работает даже при неизвестной версии и пустом списке тем; при запуске соединённого приложения он отправляется автоматически.
- Исправлена диктовка: приложение использует штатный сетевой клиент Electron вместо встроенного Node-клиента, для которого воспроизводился ответ Cloudflare 403. Текст сначала попадает в редактируемый черновик, не отправляется собеседнику автоматически и не заменяет ранее введённый текст.
- В журнале диагностики сохраняются этапы обмена версиями и коды ответов сервиса диктовки. Аудио, распознанный текст, личные поручения и данные входа в журнал не записываются.

## Обновление

Обновите оба приложения до 1.0.0, чтобы получить одинаковый интерфейс и исправления. Установщики доступны для Windows x64 и macOS Apple Silicon / Intel; файлы автоматического обновления включены в релиз.

Выбранный исходный чат, темы, результаты и текстовые черновики сохраняются. Повторно выгружать чат или проходить первый запуск не нужно. Перед перезапуском завершите диктовку: нерасшифрованное аудио хранится только в памяти.

Поручение для продолжения по-прежнему сначала обрабатывает свой агент. На другой компьютер отправляется его подготовленная реплика, а не исходный текст поручения.

## Проверки и ограничения

- Автоматические тесты покрывают сохранение данных, продолжение бесед, доставку сообщений в открытый разговор, совместимость обмена версиями с 0.3.29, повторные события, ошибки сети и диктовку.
- В локальном Windows-приложении подтверждены получение версии второго компьютера и успешная расшифровка через новый сетевой клиент.
- Ручная проверка микрофона на реальном Mac не проводилась. Диктовка использует внутренний недокументированный сервис ChatGPT; его доступность не гарантируется.
- macOS-сборки пока не имеют Apple notarization. Инструкция установки: [INSTALL_FOR_CODEX.md](https://github.com/Dobrygnom/family-bridge/blob/v1.0.0/INSTALL_FOR_CODEX.md).
