# Установи и настрой Family Bridge на этом компьютере

Выполни задачу полностью и самостоятельно. Пользователь не должен вручную редактировать файлы или выполнять команды. Не используй браузер для чтения истории ChatGPT и не удаляй существующие чаты.

Это новый компьютер и отдельный аккаунт/чат владельца. Не переноси thread ID, путь к памяти или личный архив другого человека.

Официальный репозиторий Family Bridge: `https://github.com/Dobrygnom/family-bridge`

## 1. Диагностика

1. Определи macOS/Windows и архитектуру процессора.
2. Проверь наличие Codex Desktop и Codex CLI командами `codex --version` и `codex login status`.
3. Если CLI отсутствует, установи его официальным поддерживаемым способом.
4. Если вход отсутствует, запусти официальный `codex login` и попроси пользователя выполнить только интерактивную авторизацию.

## 2. Установка приложения

1. Получи последнюю подходящую сборку Family Bridge из GitHub Releases репозитория `https://github.com/Dobrygnom/family-bridge`.
2. Проверь опубликованный checksum и установи приложение стандартным способом ОС.
3. Запусти его и проверь, что UI показывает установленный и авторизованный Codex.
4. Включи автозапуск и проверь работу после закрытия окна.

Если release-сборки нет, клонируй репозиторий, установи Node.js LTS, выполни `npm ci`, `npm test`, `npm run build`, собери и установи приложение. Rust не требуется: проект использует Electron.

## 3. Базовый чат и личная память

1. Открой отдельный раздел «Контекст» в Family Bridge и нажми «Выбрать чат».
2. Попроси владельца выбрать нужную пару «проект — чат» из списка. Приложение получает этот список напрямую из локального Codex; браузер, ручная выгрузка и thread ID не нужны.
3. После выбора проверь, что UI явно показывает проект, название чата, количество выгруженных реплик владельца и время обновления.
4. Family Bridge хранит только исходные реплики владельца из выбранного чата в локальном `psychologist-memory/style-samples.jsonl`. Реплики агента туда не попадают.
5. При выборе другого чата предыдущая выгрузка заменяется данными нового источника. Ничего не смешивается.
6. Приложение обновляет выбранный контекст при запуске, каждые шесть часов и по кнопке «Обновить выгрузку».
7. Дождись блока «Люди и темы». Проверь, что приложение отдельно показывает, о ком каждая тема и с кем её предлагается обсудить.
8. Попроси владельца исправить ошибочно определённых людей/адресатов и явно разрешить только подходящие темы. Перекрёстная тема, например о любовнике для мужа, не должна передаваться без отдельного разрешения.
9. Не создавай отдельную задачу или heartbeat-автоматизацию синхронизации: она больше не требуется.

## 4. Связывание

1. В приложении укажи, как называть владельца. Не пытайся определять имя по порядку создания приглашения, email, системному имени или содержанию чата.
2. Перед созданием или вводом приглашения попроси владельца выбрать, какому человеку из его локального контекста соответствует второй компьютер.
3. На первом компьютере создай одноразовое приглашение; на втором выбери соответствующего человека в его собственном контексте и вставь приглашение партнёра.
4. Проверь, что в общую очередь попали только разрешённые темы, адресованные выбранному человеку. Исходные реплики и список неразрешённых тем передаваться не должны.
5. Проверь encrypted round-trip тестовой нейтральной темой без личных данных.
6. Погаси одноразовое приглашение после успешного связывания.

## 5. Финальная проверка

1. Проверь установленный UI: на обзоре должны быть только соединение и темы, а выбор базового чата и маршрутизация — в отдельном разделе «Контекст».
2. Запусти mock self-test без расхода Codex.
3. После подключения двух реальных компьютеров запусти короткий тест агентов на нейтральной теме.
4. Если тем несколько, проверь, что они стартуют как отдельные разговоры, а сбой одной темы не теряет остальные.
5. Подтверди доставку, строгую очередность внутри каждого диалога, лимит ходов, итог и восстановление после перезапуска.
6. Сообщи пользователю только итог, расположение локальной памяти и способ открыть приложение.

Не загружай полный личный архив в GitHub, Supabase, логи установки или сообщения второму агенту.

## Что можно спросить у владельца

Разрешены только действительно необходимые вопросы:

- подтверждение интерактивного входа в Codex, если аккаунт ещё не авторизован;
- одноразовый код приглашения Family Bridge, созданный партнёром;
- выбор базового чата в интерфейсе Family Bridge;
- кого из найденных в контексте людей представляет второй компьютер;
- подтверждение или исправление маршрутизации конкретных тем.

Не требуй от владельца программный код, thread ID, команды терминала или ручное редактирование файлов.
