# Установи Family Bridge на этот Mac

Это задача для Codex Desktop на компьютере владельца. Выполни её полностью сам. Не проси владельца открывать Terminal, вводить команды, искать thread ID, выгружать чат через браузер или редактировать файлы.

Официальный репозиторий: `https://github.com/Dobrygnom/family-bridge`

## Что уже является предпосылкой

Если владелец открыл эту инструкцию в Codex Desktop, значит Codex уже установлен и вход в аккаунт выполнен. Не устанавливай отдельный Codex CLI: Family Bridge версии 0.3.6 и новее умеет использовать Codex, встроенный в `/Applications/Codex.app`.

Поддерживаемый сценарий этой инструкции — Mac с Apple Silicon. Проверь `uname -m`: ожидается `arm64`. Если это Intel Mac, не ставь случайную x64-сборку — сообщи владельцу, что для этого компьютера сначала нужен отдельный совместимый сценарий Codex.

## Установка

1. Через GitHub API найди последний опубликованный release репозитория. Его версия должна быть не ниже `v0.3.6`.
2. Скачай только два файла из этого release:
   - `Family-Bridge-<версия>-arm64.dmg`;
   - `SHA256SUMS.txt`.
3. Проверь SHA-256 DMG по строке из `SHA256SUMS.txt`. При несовпадении немедленно остановись.
4. Заверши старый Family Bridge, если он запущен. Смонтируй DMG, скопируй `Family Bridge.app` в `/Applications`, затем размонтируй образ.
5. У сборки пока нет Apple notarization. Только после успешной проверки SHA-256 сними quarantine-атрибут с `/Applications/Family Bridge.app`, чтобы первый запуск не требовал от владельца обходить Gatekeeper вручную.
6. Запусти `/Applications/Family Bridge.app` и оставь Codex Desktop открытым.

Не собирай приложение из исходников и не устанавливай Node.js, npm, Homebrew или отдельный `codex`, если опубликованный release доступен.

## Первый запуск

1. Убедись, что Family Bridge показывает Codex как подключённый.
2. На первом экране владелец сам выбирает свой базовый чат ChatGPT. Ничего не выбирай за него и не пересказывай содержимое найденных чатов.
3. После выбора приложение само:
   - выгружает только реплики владельца;
   - определяет стиль общения;
   - находит упомянутых людей и темы;
   - показывает прогресс;
   - предлагает владельцу проверить адресатов и разрешить темы.
4. Дождись состояния, в котором список людей и тем готов к проверке. Не создавай отдельную задачу синхронизации, heartbeat или ручной экспорт: они больше не нужны.
5. Только после проверки тем владелец выбирает, к какому найденному человеку относится второй компьютер, и создаёт либо вводит код приглашения.

Если список чатов не появился, не подменяй его браузерной выгрузкой. Проверь, что Codex Desktop открыт, эта локальная задача существует и установлена Family Bridge 0.3.6 или новее. Перезапусти оба приложения один раз. Если проблема остаётся, сообщи точный текст ошибки и ничего не выдумывай.

## Диктовка (начиная с 0.3.29)

В ответах агенту и при добавлении темы есть «Надиктовать». При первом использовании macOS попросит разрешение на микрофон для Family Bridge — это решение принимает сам владелец. Запись отправляется непосредственно в OpenAI для расшифровки; полученный текст сначала появляется в черновике и не отправляется партнёру автоматически. Отдельный API-ключ и локальная модель распознавания не нужны. Внутренний сервис диктовки может быть временно недоступен; ввод с клавиатуры остаётся доступным.

Не меняй хранилище авторизации Codex и не копируй auth.json ради диктовки. Если вход недоступен, сохрани рабочую настройку и сообщи об ограничении. Для проверки кнопки не записывай микрофон без действия владельца.

## Что проверить в конце

- установленная версия Family Bridge;
- имя скачанного DMG и совпавший SHA-256;
- приложение находится в `/Applications/Family Bridge.app` и запускается;
- Codex определяется без отдельной установки CLI;
- экран выбора базового чата открывается и показывает чаты;
- после выбора виден процесс подготовки людей и тем;
- исходные реплики не отправлялись в GitHub, Supabase, установочные логи или на второй компьютер.

Сообщи владельцу короткий итог: установленную версию, путь к приложению и что ему теперь нужно сделать в интерфейсе. Не включай в отчёт содержание личного чата.
